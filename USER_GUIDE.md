# User guide

Konomi starts on Taste. Add books, films, and shows from Library, give them a personal 1–10 score, and mark their status. After enough ratings, Taste can generate a profile describing the patterns in what you love; Discover can then request personalized recommendations.

Connections are managed in Settings. Anthropic is required for taste analysis and recommendations, TMDB for film/television search, and Google Books is optional. Keys are saved in Keychain and can be removed independently.

All library data is local to the device. Goodreads CSV import is supported. The built-in CSV export is a readable summary and should not be treated as a complete backup.
